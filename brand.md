# Brand — AgentPay Guard

_Status: active_

## Product
AgentPay Guard — programmable on-chain payment control for AI agents. Users fund a vault, authorize an agent, and set spending rules enforced by a smart contract on Arc.

## Direction
Institutional fintech × blockchain infrastructure. Stripe clarity, Linear restraint, Fireblocks trust posture — not copied layouts. Editorial, precise, expensive.

## Palette
| Role | Value | Notes |
|---|---|---|
| Foundation | `#070b12` | Deep midnight |
| Elevated | `#0d1520` | Panels / surfaces |
| Ink | `#f3f5f7` | Soft ivory / warm white |
| Secondary | `#9aa8b8` | Controlled secondary text |
| Border | `rgba(255,255,255,0.10)` | Neutral, restrained |
| Accent | `#4a9eff` | Electric blue / muted cyan |
| Accent soft | `#7eb6ff` | Hover / highlights |
| Success | `#3d9a6a` | Confirmed payment states only |
| Danger | `#d45d6a` | Rejected / policy fail |

## Typography
- Display / wordmark: Space Grotesk
- Body / UI: DM Sans
- Data / addresses: JetBrains Mono

## Tone
Direct, precise, credible. No hype, no absolute security guarantees, no invented metrics. Explain control: user → vault → rules → authorized agent → payment.

## Do
- Let typography, spacing, and composition carry the design
- Show the product control model visually
- Claim only what the contract and deployment support

## Don't
- Purple AI aesthetics, glowing orbs, glassmorphism everywhere
- Generic robot / brain / coin illustrations
- Fabricated audits, partnerships, user counts, or mainnet claims without evidence
